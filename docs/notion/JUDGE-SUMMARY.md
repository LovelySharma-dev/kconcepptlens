### Problem
STEM students still reconstruct spatial and temporal ideas from flat ink. Unchecked generative tools can invent structures. Learners with different attention, reading, sensory, and bandwidth needs are underserved by one-size pages—and harmed by fake accessibility claims.

### Solution (what you can show)
1. **Prove before teaching** — Home linked-list lesson: valid reverse → break cycle → Floyd stop → repair → continue.  
2. **Confirm before explain** — Practice materials reviewed by the learner; rule-based math/chem steps.  
3. **Meaningful Cloudinary** — Server-signed uploads; Explore / Focus / Low-data deliveries of one plant-cell illustration (verify local vs Render status).  
4. **Inclusive by choice** — Combinable learning themes, Voice Guide, focus ruler; ISL foundation without inventing sign video.  
5. **Skills-guided media engineering** — Cloudinary Skills Pack in `.agents/skills`; React Starter Kit packages adapted, **CLI scaffold not used**.
